# CSC450-Autonomous-Vehicles-Senior-Research
This repository will be a GitHub repository for project related materials.


The objective for my Senior Research project will be to Use a PyGame model to quantify the increased efficiency of autonomous vehicles (AVs) in terms of speeds and road space used, and how this influences demand for AVs.​ Other factors I plan to consider when developing my simulation include the speed of cars on the road, the efficiency at which they drive, as well as varying amounts of traffic on the simulated road to see how the AVs hold up.
